# Design rules: decisions that apply to a whole family

Rules the user accepted during `/co-planner` sessions. Each applies to every member of its family, including members added later: new work is checked against this file before it is planned. A rule that becomes a hard invariant can move into the project's own instructions (`CLAUDE.md`, `AGENTS.md`).

To change or drop a rule, edit it in place and keep a dated note of why.
