# Insights: what emerged while planning and building

Log only what really emerged; never force it. Grade: **A** clear and cheap now, **B** good with a caveat, **C** marginal, **D** weak (kept so it isn't re-proposed).

Record evidence or mark a hypothesis, benefit, effort/dependencies, caveat, validation and disposition. Extend existing table entries with a short note when needed; no mandatory table migration. Revisit a rejected idea only when new evidence addresses its rejection.
